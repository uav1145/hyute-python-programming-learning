Hướng dẫn sử dụng và thực hành Python

Trang học liệu trên GitHub Pages hoạt động như sách tương tác; chương trình Python được thực thi trên máy tính hoặc notebook thực tế.

1. Cách học một bài

  1. Đọc mục tiêu và phân tích bài toán theo I/O, giả thiết, đơn vị.
  2. Viết mã giả, dự đoán kết quả và lần vết thuật toán trên website.
  3. Tải tệp .py trong bài và chạy bằng Python 3.
  4. Sử dụng dữ liệu data/ đúng vị trí; kiểm thử ít nhất các ca trong bảng.
  5. Trả lời trắc nghiệm, ghi nhật ký và tự đánh dấu hoàn thành.

2. Cài đặt và môi trường

Khuyến nghị sử dụng Python 3 bản còn được hỗ trợ tại thời điểm triển khai, VS Code với Python extension hoặc Jupyter. Các bài 1–10 phần lớn dùng thư viện chuẩn; bài 11–20 bổ sung NumPy, pandas, Matplotlib và SciPy.

Lệnh tham khảo · Windows Terminal / PowerShell
python --version
python -m pip install numpy pandas matplotlib scipy
python code/bai_01.py
python code/bai_12.py
python code/bai_17.py

Nếu lệnh pythonpy khi Python Launcher được cài. Không phải máy nào cũng có sẵn lệnh py.

3. Cấu trúc thư mục cần giữ nguyên

HYUTE_Python_KyThuat_20Bai/ ├── index.html ├── lessons/bai_01.html ... bai_20.html ├── code/bai_01.py ... bai_20.py ├── data/nhiet_do_mau.csv, dien_ap_acquy.csv ├── assets/style.css, app.js ├── thuat_ngu.html, huong_dan.html └── QA_REPORT.md

Chạy lệnh trong thư mục gốc dự án. Các bài có truy xuất tệp tìm dữ liệu theo vị trí tương đối của chính tệp .py, giúp chương trình chạy nhất quán khi đổi thư mục làm việc.

4. Thực hành trên Colab

Colab không tự có thư mục dự án trên máy cá nhân. Để chạy các bài 9, 12, 13, 19, 20 trong Colab, bạn phải tải tệp CSV vào đúng đường dẫn hoặc sửa đường dẫn trong mã. Những ví dụ đặt đường dẫn theo __file__ dành cho chạy tệp .py; trong ô notebook cần thay bằng đường dẫn dữ liệu trên Colab.

Không có yêu cầu sinh viên trả phí hay có GPU; chương trình ví dụ có thể chạy trên CPU.

5. Quy tắc đánh giá và bảo vệ kết quả

Chấm theo bằng chứng: mô tả bài toán, thuật toán, mã, thử nghiệm và giải thích. Mỗi bài có rubric tham khảo 100 điểm; thang điểm học phần cuối cùng do đề cương chính thức quyết định.

Chưa có hệ thống đăng nhập sinh viên hoặc lưu điểm tập trung. Các mục đánh dấu và ghi chép nằm trong localStorage, có thể mất khi xóa dữ liệu trình duyệt.
